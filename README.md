# Pickup Management System — Production Starter

Includes login, admin/staff roles, dashboard, pickup entry/edit, search/filter, CSV export, user management, SQLite database, and imported September 2026 records.

Run:
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://localhost:5000

Initial admin: admin / admin123
Before internet deployment, change the password and SECRET_KEY.
